1. README
What it is

An interactive, browser-based practice tool that teaches children to instantly recall the number bonds to 10 (0+10, 1+9, 2+8 … 5+5) using dice-dot visuals instead of rote counting. It runs as a single, self-contained HTML file — no installation, no internet connection required after download, and no account or login.

Who it's for
Children working at a Reception–Year 2 level (ages ~5–7) who already know dice patterns 1–5, or want to learn them
Parents supporting learning at home
Tutors and teachers wanting a ready-made, low-prep activity for 1:1 or small-group sessions
Home-schoolers looking for a self-marking practice resource
How the learning journey works
Dice Patterns Recap (1–5) (optional — "Full Start" only) A quick refresher on standard dice-dot layouts before diving into bonds to 10.
Flash Recognition Quiz A dice pattern flashes briefly on screen; the child identifies the number from memory to build instant recall.
Learn: Making 10 Introduces the bonds to 10 visually — numbers 6–9 are shown as "5 dots + extra dots" across two dice, mirroring how children are taught to subitise in KS1.
Guided Fill One die is already shown; the child taps dots to complete the missing die so the pair makes 10.
Challenge Fill Both dice start empty — the child fills in the full pair from scratch. Includes 9 questions and a running score.
Number Quiz Numbers only, no dice — multiple-choice questions such as 3 + ☐ = 10. 12 questions with an end score.
Printable Worksheets Three ready-to-print, paper-based worksheets (write the missing number / draw the dots / number quiz) so children can practise away from the screen. Includes name, date, and score fields for teacher/parent marking.

Children can choose:

⭐ Full Start — includes the dice recap; best for children new to the visual method
⚡ Quick Start — skips straight to the bonds-to-10 practice; best for children who already know dice patterns 1–5
Using the tool
Download the .html file.
Open it by double-clicking, or by dragging it into any modern web browser (Chrome, Safari, Edge, Firefox).
Works on desktop, laptop, tablet, and interactive whiteboards. Touch and mouse/click both supported.
No Wi-Fi needed once downloaded — works fully offline.
To print worksheets, click the 🖨️ Print button at any point in the activity and choose "Save as PDF" or send to a printer.
